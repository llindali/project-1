# WACC convention

Base nominal USD scenario WACC: **9.00%**. Illustrative component build:

WACC = equity weight x required equity return + debt weight x pretax cost of debt x (1 - marginal tax).

95% equity x 9.263% equity cost + 5% debt x 5% pretax debt cost x (1 - 20% tax) = 8.99985%, rounded 9.00%.
